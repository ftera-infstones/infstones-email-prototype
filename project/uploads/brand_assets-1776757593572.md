## 5. Layout

### Structure

```
<Layout>
  <SideMenu />       ← mobile drawer
  <Header />         ← fixed top nav
  <main>
    <page content />
    <Footer />
  </main>
  <PreviewImage />   ← lightbox overlay
</Layout>
```

### Header

- Desktop height: `80px` (`$header-height`)
- Mobile height: `48px` (`$header-mobile-height`)
- Promotion bar: `40px` (`$promotion-bar-height`)
- Behavior: adds `.headerScrolled` class on scroll; hides on mobile scroll-down, reveals on scroll-up
- Logo: full (with text) on desktop, icon-only on mobile
- Special: `/about-us` gets `.aboutUsHeader` variant style

### Page Themes

Two theme modes controlled by `WHITE_THEME_PAGE`:

| Theme | Pages | Background |
|---|---|---|
| Dark (default) | All other pages | `#0B0E1E` |
| White | `/news`, `/blog`, `/contact-us`, `/bug-bounty-program`, `/events` | `#F5F5F6` |

## 6. Components

### Button

```tsx
<Button
  type="primary" | "outline"   // variant
  size="" | "big" | "midium"   // size
  state="" | "success" | "failed" | "loading"
  resizeable={bool}            // responsive auto-resize
  bold={bool}
/>
```

| Prop | Effect |
|---|---|
| `type="primary"` | Filled `#EDB500`, dark text `#0B0E1E` |
| `type="outline"` | Border `#EDB500`, text `#EDB500` |
| `size="big"` | 40px height, 16px font, 20px border-radius |
| `size="midium"` | 32px height, 14px font, 16px border-radius |
| `resizeable` | 40px on desktop, 32px on mobile |
| `state="loading"` | Shows SVG spinner alongside children |
| `state="success"` | Replaces content with ✓ SUCCESS |
| `state="failed"` | Replaces content with ✗ FAILED |

Shared styles: `border-radius: 40px`, `text-transform: uppercase`, `font-weight: 700`

### Footer

- Left: Logo + tagline + social icon links
- Center: Navigation columns (from `navs` config)
- Right: Newsletter subscription (email input + Subscribe button)
- Bottom bar: Copyright + Terms links + Cookie Settings
- Lazy-renders logo via Intersection Observer

## 7. SASS Mixins

```sass
// Layout
@include flex-row-center        // display:flex; align+justify: center
@include flex-row-between       // space-between
@include flex-row-end
@include flex-row-start
@include flex-column-center
@include flex-column-end
@include flex-column-between
@include flex-column-start

// Media
@include respond($min, $max)    // custom range media query

// Background
@include bg-img                 // cover, center, no-repeat
@include background-cover

// Typography
@include text                   // Syncopate 700 24px uppercase #D7DADE
@include bannerTitle            // Syncopate 700 54px #EDB500 with logo prefix

// Buttons
@include land-button            // gradient CTA button style
@include font-empty             // stroke-only text (transparent fill)

// Content sizing
@include content-width-resize   // responsive max-width
```

### Unit Functions

```sass
p2r($px)   // px → rem (base 16px)
vw($px)    // px → vw (base 1920px viewport)
```
